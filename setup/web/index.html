STEP 01 / CONNECT

Start with your phone.

Use a computer with Chrome or Edge and a USB data cable. This page cannot connect to the phone it is running on.

  • NAVEE is signed in and already works with your scooter.
  • Your scooter is nearby, parked, and powered on.
  • Other scooter apps and computer ADB tools are closed.

This first version supports the phone’s main personal Android user. Work profiles and secondary users are not supported.

How to enable USB debugging
  1. On Android, open Settings → About phone. Tap Build number seven times (Samsung: About phone → Software information first).
  2. Open Developer options and turn on USB debugging.
  3. Connect a data-capable USB cable. Unlock the phone.

Work-managed phones may block debugging. On Windows, your phone’s USB driver may be required.

USB debugging is powerful.

It grants this page broad developer access to the selected phone, beyond the one message we need. Continue only for a phone and scooter you own or have permission to set up.

We use a temporary browser key. On the phone prompt, leave “Always allow from this computer” unchecked.

Chrome asks you to select a device. Android then asks you to approve USB debugging. You can cancel either prompt.

STEP 02 / YOUR APPROVAL

A small capture, clearly explained.

Android phone connected

When you approve, this helper will:

  1. Save NAVEE’s existing log setting and start a cleanup timer.
  2. Temporarily enable NAVEE logging and restart the NAVEE app.
  3. Read only fresh NAVEE Bluetooth authentication messages while you connect to your scooter.
  4. Close NAVEE and restore its original log setting before offering any export.

NAVEE itself may log more while verbose logging is enabled; this helper reads only the filtered authentication messages. It never reads your NAVEE password or uploads the capture.
